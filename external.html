    08
WAF Detection

  

  
Fingerprint the WAF before fuzzing or injecting payloads. A WAF changes everything  -  encoding requirements, rate limits, and evasion all depend on what product sits in front of the target. Run wafw00f first, confirm via headers, then decide if bypass is needed before running ffuf or sqlmap.


  

    
›
WAF Fingerprinting

    

      
wafw00f sends crafted requests and analyses responses to fingerprint 180+ WAF products. Always run with -a to test all signatures  -  some WAFs don't respond to the first probe.

Service Enumeration

  

  
Once nmap confirms an open port, each service needs targeted probing. Start with the fastest passive check (banner grab, anonymous access) before moving to active enumeration. Most initial access on real engagements comes from one of these services being misconfigured.


  

    
›
FTP  (21)

    

      
Anonymous login is the first thing to check — it is still misconfigured on legacy systems, NAS devices, and embedded hardware more often than expected.

SSH  (22)

    

      
Modern OpenSSH (8.x+) is not vulnerable to timing-based user enum. Check the version first — user enumeration only applies to OpenSSH < 7.7.

SNMP  (UDP 161)

    

      
SNMP v1/v2c community strings travel in cleartext. public and private are still the most commonly found on network devices, printers, and UPS systems in enterprise environments. A successful walk leaks the entire device config, routing tables, and running processes.

LDAP  (389 / 636)

    

      
Anonymous bind is disabled by default on Active Directory but is often enabled on standalone OpenLDAP instances and old directory servers. A successful null bind leaks all users, groups, and OUs without credentials.

SMB  (445)

    

      
SMB should never be internet-facing but routinely is on misconfigured Windows servers and cloud instances. Null sessions and guest access are still found. Always check for EternalBlue (MS17-010) on unpatched systems — it is still present in the wild.

RDP  (3389)

    

      
Check whether NLA (Network Level Authentication) is enforced — without it, you reach the login screen without credentials, leaking the hostname and enabling further attacks. BlueKeep (CVE-2019-0708) is still unpatched on a significant portion of real Windows Server 2008 / Windows 7 systems.

NFS  (2049)

    

      
NFS exports with no_root_squash or world-readable permissions are a direct path to credential access — you can mount the share and read /etc/shadow, SSH keys, and application configs without authentication.

    15
Email Security

  

  
Email authentication misconfiguration is one of the most impactful findings on real engagements — a missing or permissive DMARC record means you can send email as the CEO with no technical exploit. Check this early: it takes under two minutes and is purely passive DNS.


  

    
›
SPF / DMARC / DKIM Analysis

    

      
Quick decision tree: No SPF = spoofable. SPF ~all = soft-fail (most mail clients accept it). SPF -all + DMARC p=reject = hardened. DMARC p=none = monitoring only, spoofing still works.
